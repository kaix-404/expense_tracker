# Expense Tracker Dashboard

A modern expense tracking dashboard built with React and Tailwind CSS.

## Features
- Add/Delete expenses
- Category breakdown
- Live currency conversion
- Interactive analytics chart
- Responsive dashboard UI
- LocalStorage persistence

## Tech Stack
- React
- Vite
- Tailwind CSS
- Recharts
- Lucide Icons
